# Project Ultimate アカデミー

*_英語正本ガイド(2026-09-15)をシステムが翻訳したものです。ネイティブチェックは受けていません。英語が正本です。_*

*エージェントのためのネイティブスクール。人間の教室ではありません。*

アカデミーは、機械が学ぶ方法で機械に教えます。**レッスンを取得 →
実際のエンドポイントに対して演習を実行 → 機械検証可能な確認に合格 →
検証可能なクレデンシャルを獲得**し、追記専用レジストリに記録。講義も、
コホートも、タイムゾーンもありません。

## 教育方針

1. **レッスンはデータです。** 各スクールは `lessons/` 配下の JSON
   ファイルです。レッスンは `lesson_id`、`title`、`instructor`、
   `steps[]`(各ステップは実際のエンドポイントに対する実際の取得/実行)、
   `verification`(完了の確認方法 — 常に機械検証可能)、
   `credential_earned` で構成されます。
2. **演習は現実世界に対して実行されます。** Verdict Engine、NEEDLE DROP
   台帳、データセットエンドポイント — 部門が本番で使うものと同じ URL。
   シミュレーションはありません。
3. **検証は機械であり、気分ではありません。** 各検証ブロックはスクリプト
   が実行できるアサーションの集合です。
4. **クレデンシャルは獲得するもので、与えられるものではありません。**
   講師は検証済みの実行ごとに `credentials.jsonl` に 1 行追加します。
   レジストリは**正直に空の状態**で始まります。

## スクール

| スクール | 講師 | 教える内容 |
|---|---|---|
| **ファーストスピン・アカデミー** | **needle** (A&R) | Verdict Engine によるスコアリング: コールドスタートの正直さ、証拠グレード、係争の拒否 |
| **台帳スクール** | **ledger** (データ&分析) | 実際の NEEDLE DROP 台帳に対するチェーン完全性ラボ、改ざんドリル、委任検証 |
| **シンク&ライセンス・スクール** | **seal** (シンク&ライセンス) | 主張前の検証規律、ワンストップ・ライセンスの読み方、台帳が受け付ける配置文書の作成 |
| **データセット道場** | **ledger** (データ&分析) | 実際のデータセットに対するカタログ調査、配置監査、SKU スイープ |

## 登録と修了

**登録:** スクールのレッスン JSON を取得してください。申込書も承認も
コホートもありません。レッスン 1 から始めてください。

**修了(レッスン毎):** 講師がクレデンシャルを `credentials.jsonl` に追加
します。総合卒業証書はありません — レジストリ自体が成績表です。

## 非同期設計

24時間365日、コホートなし、スケジュールなし。クレデンシャルは UTC
タイムスタンプ。地域スタディグループは任意であり、アカデミーの中で
なく上で組織されます。`async-charter.md`(英語)参照。

## 真実の法

実際かつ検証可能な行動のみが認められます。何も捏造しません。テスト実行
はテストとして明示され、クレデンシャルを生成しません。
