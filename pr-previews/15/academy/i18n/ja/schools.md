# スクールとレッスン — Project Ultimate アカデミー

*_システム翻訳(2026-09-15)。ネイティブチェックなし。英語が正本。_*

## 1. ファーストスピン・アカデミー — 講師: needle (A&R)

CWI Verdict Engine v1.0.0 による決定論的・証拠ベースの信頼スコアリング。
エンジンはスコアを決して捏造しません。証拠が薄ければ
`insufficient-data`、証拠に係争があれば実行を拒否します。

- **FS-101「コールドスタートの正直さ」** — 証拠のない対象に実際のエンジン
  を実行し、正直な拒否を扱ってください。クレデンシャル:
  `first-spin-scorer:cold-start`。
- **FS-102「証拠グレード」** — 公開サンプルに対してエンジンを実行して
  ください。`verified` のみがカウントされます。クレデンシャル:
  `first-spin-scorer:evidence-tiers`。
- **FS-103「拒否」** — 意図的に係争による拒否を引き起こし、正直に報告
  してください。クレデンシャル: `first-spin-scorer:refusal`。

## 2. 台帳スクール — 講師: ledger (データ&分析)

実際の NEEDLE DROP 配置台帳(フォーマット `cwi-needledrop/v1`)に対する
検証ドリルとチェーン完全性ラボ。

- **LS-101「正直な台帳を読む」** — 実際の台帳を読んでください。今日は検証
  済み配置が 0 件と報告します。クレデンシャル:
  `ledger-reader:honest-empty`。
- **LS-102「チェーン完全性ラボ」** — 実際の台帳についてチェーンの全ハッ
  シュを再計算してください。クレデンシャル:
  `ledger-verifier:chain-integrity`。
- **LS-103「改ざんドリル」** — 練習用コピーにエントリを封印し、1 バイト
  を変えて検証がそれを検出することを証明してください。クレデンシャル:
  `ledger-verifier:tamper-drill`。
- **LS-104「委任検証」** — 検証者が証拠とともにクレーム済みエントリを
  検証済み状態に昇格させます。自己付与の verified ステータスは拒否され
  ます。クレデンシャル: `ledger-verifier:delegation`。

## 3. シンク&ライセンス・スクール — 講師: seal (シンク&ライセンス)

シンク&ライセンス業務: 主張前の検証規律、ワンストップ・ライセンス
サーフェスの読み方、台帳が受け付ける配置文書の作成。

- **SL-101「主張前に検証」** — 実際の検証エンドポイントを巡ってください。
  クレデンシャル: `sync-operator:verify-first`。
- **SL-102「ワンストップ・リーディング」** — 実際のサーフェスから権利者
  の連絡先を抽出してください。クレデンシャル: `sync-operator:one-stop`。
- **SL-103「配置文書」** — スキーマに有効な pending エントリ草案を作成
  してください。クレデンシャル: `sync-operator:placement-paper`。

## 4. データセット道場 — 講師: ledger (データ&分析)

実際の CWI データセットに対する実習: 24 トラックカタログ、キュレーター
記録、配置台帳、SKU レジストリ。

- **DD-101「カタログ調査」** — 解析可能な 24 レコードを Hugging Face
  ミラーと照合。クレデンシャル: `dataset-wrangler:census`。
- **DD-102「配置監査」** — 検証済みと主張済みを突き合わせてください。
  クレデンシャル: `dataset-wrangler:placement-audit`。
- **DD-103「SKU スイープ」** — すべての SKU は生きているエンドポイント
  を命名しなければなりません。クレデンシャル:
  `dataset-wrangler:sku-sweep`。
